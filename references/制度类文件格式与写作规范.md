# 华中担保制度类文件格式与写作规范

> 版本：v1.0　编制依据：对本单位三份制度文件 docx 的 XML 级实测
> 标本：①《华中（武汉）融资担保股份有限公司制度建设管理办法（征求意见稿）》②《华中担保固定资产管理办法》③《华中担保无形资产管理办法》
> 适用：名称含“制度”“办法”“规定”“细则”“规范”“清单”“政策”“操作规程”“实施细则”“工作指引”的内部制度类文件。
> 三处标本差异已拍板：**条号用仿宋_GB2312三号加粗**（备选黑体）、**章/节/条号后 2 个半角空格**、**“附则”作章名时两字间空 2 个半角空格（写作「附  则」）**。

---

## 一、体例：分章贯条 / 条文到底

依《制度建设管理办法》第二十三条：

- **内容较丰富** → 采“分章贯条”式：按不同内容分为不同**章**；章之下分**条**编排；条文数较多时可在章之下增加**节**；条目采用**大流水号**编排（条号贯穿全文连续，不按章重新起算）。
- **内容较简短** → 采“条文到底”式：全部内容直接分为不同条目，顺序编排，不设章。
- 条下可分**款**，款内可列**项**，项下可列**目**。

### 层次序数体系（与公文类完全不同，切勿混用）

| 层级 | 序数写法 | 字体字号 | 对齐/缩进 |
|---|---|---|---|
| 章 | 第X章　X X（中文数字；序号后用 **2 个半角空格**） | 黑体 三号 | **居中**，独立成段，无首行缩进 |
| 节 | 第X节　X X（中文数字；同上） | 仿宋_GB2312 三号 **加粗** | **居中**，独立成段，无首行缩进 |
| 条 | 第X条　…（中文数字 + 大流水号；条号后 **2 个半角空格**） | 条号：仿宋_GB2312 三号**加粗**（备选：黑体三号）<br>条文：仿宋_GB2312 三号 | 两端对齐，**首行缩进 2 字符** |
| 款 | **不编号**，另起自然段 | 仿宋_GB2312 三号 | 首行缩进 2 字符 |
| 项 | （一）（二）（三）中文数字加括号 | 仿宋_GB2312 三号 | 首行缩进 2 字符 |
| 目 | 1.　2.　3.（阿拉伯数字加下脚点） | 仿宋_GB2312 三号 | 首行缩进 2 字符 |

**禁用**：公文体「一、」「（一）」「1.」「（1）」四层序数不得用作制度的一级/二级层次。制度类只有“章—节—条—款—项—目”六层，且“一、”这一写法在制度中**不出现**。

**空行禁忌**：条与条之间、章与章之间**不留空行**；靠段前段后 0 + 固定行距形成紧排效果。

## 二、内容骨架（依《制度建设管理办法》第二十二条）

一份制度原则上应包含下列六项内容，对应到章的分配为：

| # | 法定内容 | 通常落位 |
|---|---|---|
| （一） | 制定目的及依据 | 第一章 总则 |
| （二） | 适用范围和定义 | 第一章 总则 |
| （三） | 管理体制和职责权限 | 第二章（职责类章） |
| （四） | 管理规范的内容、要求与流程 | 中间各章（按业务链条切分） |
| （五） | 解释责任部门 | 末章 附  则 |
| （六） | 施行日期（试行/暂行须标注期限） | 末章 附  则 |

涉及重大经营管理事项的制度，可增设**专门责任条款**章，列明违规情形与责任处理。

### 章名用词库（实测三份标本）

- 开篇：**总则**
- 职责类：职责划分 / 管理部门及职责 / 管理职责
- 业务类：预算管理、配置管理、日常管理、资产处置、核算管理、无形资产的增加和使用、无形资产的清查和报告制度、无形资产的账务处理、制度体系与分类、制度建设计划管理、制度内容与审查、制度审批与发布、制度执行、评估与废止
- 收束类：监督检查与奖惩规定 → **附  则**

**附则**：标本中 2 份写「附则」、1 份写「附  则」。**本单位采用「附  则」**，即“附”与“则”之间空 2 个半角空格，口径与章/节/条号后一致（用半角空格，不用全角空格）。

## 三、格式规格（实测值，twips 原值可直接写入 XML）

### 3.1 版面

| 项目 | 值 | 换算 |
|---|---|---|
| 用纸 | A4 纵向：`w=11906 h=16838`（twips） | 210mm × 297mm |
| 页边距 | `w:pgMar top="2041" bottom="2041" left="1531" right="1531" header="851" footer="992" gutter="0"` | 上3.6cm 下3.6cm 左2.7cm 右2.7cm；页眉1.5cm 页脚1.75cm |
| 版心 | 宽 8844 twips × 高 12756 twips | 15.6cm × 22.5cm；约 28 字 × 21 行 |
| 行距 | `<w:spacing w:line="600" w:lineRule="exact"/>` | **固定值 30 磅**（不是公文的 28 磅） |
| 段前段后 | 全部 0 | 无 `beforeAutospacing/afterAutospacing`、无 `w:before/w:after` 非零值 |
| 文档网格 | `<w:docGrid w:type="lines" w:linePitch="312"/>` | — |

> 宽表附件（如超过版心宽的统计表）可单独**分节**设为 A4 横向：`w:pgSz w=16838 h=11906 orient="landscape"` + `pgMar top/bottom=1531 left/right=2041`。正文节须保持纵向。

### 3.2 字体字号

| 要素 | 字体 | 字号 | 对齐 | 备注 |
|---|---|---|---|---|
| 文件标题第 1 行（单位全称） | 方正小标宋简体 | 二号（`sz=44`） | 居中 | 如「华中（武汉）融资担保股份有限公司」 |
| 文件标题第 2 行（制度名称） | 方正小标宋简体 | 二号（`sz=44`） | 居中 | 如「固定资产管理办法」 |
| （征求意见稿） | 楷体 | 三号（`sz=32`） | 居中 | 仅征求意见稿加 |
| 章标题 | 黑体 | 三号（`sz=32`） | 居中 | 须显式清零首行缩进 |
| 节标题 | 仿宋_GB2312 | 三号，加粗 | 居中 | 同上 |
| 条号 | 仿宋_GB2312 三号**加粗**（默认口径）；备选：黑体三号 | 三号 | — | 已定，见下行说明 |
| 条文 / 款 / 项 / 目 | 仿宋_GB2312 | 三号 | 两端对齐 | |
| 西文与阿拉伯数字 | Times New Roman | 随正文 | — | `w:ascii="Times New Roman" w:hAnsi="Times New Roman"` |
| 页码 | 宋体 | 四号（`sz=28`） | 居中 | 形如 `- 1 -` |
| 附件表格内文字 | 仿宋_GB2312 | 小四（`sz=24`） | 表头居中，数据左对齐 | |
| 附件标题 | 方正小标宋简体 | 二号（`sz=44`） | 居中 | 另页起 |

### 3.3 页码

- 位置：页脚，**居中**（不用公文式的“单右双左”）。
- 形式：`- 1 -`，数字为半角阿拉伯数字，用 `PAGE` 域。
- 字号字体：宋体 四号。
- 页脚距页底：`w:pgMar w:footer="992"`（1.75cm）。
- 标本实现方式为页脚内浮动文本框（WPS 产物）；**生成时直接写普通页脚段落即可**，效果一致且避免文本框在转 PDF / 换软件时漂移。
- 不启用奇偶页不同（标本 `settings.xml` 无 `evenAndOddHeaders`）。

### 3.4 首页与文末

- **不套红头**：无发文机关标志、无发文字号、无红色分隔线、无主送机关。首页第 1 行即单位全称。
- **无落款**：文末不写发文机关署名、不写成文日期（制度随红头文另行印发），以施行条款收尾。
- 附件说明写在末条之后：`附件：1.XXXXXXXX`　换行 `　　　　2.XXXXXXXX`，仿宋三号，首行缩进 2 字符。
- 附件另页起，页首顶格写「附件1」，下一行写附件标题（二号小标宋居中）。

## 四、写作规范（制度类）

语言底子沿用公文四大原则（准确、平实、简明、庄重），制度类在此之上另有硬约束。

### 4.1 规范用语三分法

| 意图 | 用语 | 示例 |
|---|---|---|
| 义务性 | **应当**、应 | 「各单位**应于**每年12月10日前编制……计划」 |
| 禁止性 | **不得**、严禁、不得擅自 | 「**不得**存在冲突条款」「**严禁**擅自超授权配置固定资产」 |
| 授权性 | **可以**、可 | 「可对制度进行试行」「**可**增设专门责任条款」 |

- 确需强制执行的，用“应当”“必须”；指导性内容用“宜”“参照”。
- 不使用“必须”以外的加倍强化词（“坚决”“务必”），不用“抓紧”“尽快”，改为明确时限。

### 4.2 禁止模糊表述（母法明文要求）

> 「职责分工、审批主体明确，操作流程应当具体可执行；原则上不使用‘相关单位’‘相关领导’等模糊表述。」

- 一律写实主体：「审计稽核部」「资金财务部」「资产管理部」「综合管理部」「法律合规部」「党总支办公室（董事会办公室、人力资源部）」等。
- 一律写实时限与频次：「5 个工作日内」「每年 11 月底前」「每月」「至少每年进行一次」。
- 涉及“有权审批人”的，权限不得与公司现行领导班子分工及履职清单冲突。

### 4.3 条文句式模板（标本提炼）

**目的依据条（首条）**：
```
第一条　为〔规范/加强〕……，〔明确……关系〕，〔促进/保障……〕，根据《〔法律法规/上级制度〕》等相关法律法规及公司章程的规定，结合公司实际，制定本办法。
```

**适用范围条**：
```
第X条　本办法适用于公司及各子公司。本办法所称各子公司指各级全资、控股及实际控制子公司。
```

**定义条**：
```
第X条　本办法所称“〔概念〕”，是指……的文件。
〔第二款起另起自然段，不编号，进一步限定或排除。〕
```

**列举条（分项）**：
```
第X条　……主要包括：
（一）……；
（二）……；
（三）……。
```
> 项内并列用分号「；」，末项用句号「。」。

**责任追究条**：
```
第X条　对拒不执行、违规变通……造成……的，按照公司《〔责任追究办法名称〕》有关规定追究相应责任。
```

**解释条（倒数第二或第三条）**：
```
第X条　本办法由公司〔牵头部门〕负责解释。
```

**施行条（末条）**：
```
第X条　本办法自印发之日起施行。
```

### 4.4 试行 / 暂行

- 新制定、缺乏实践经验的制度，在**名称中**标注“试行”或“暂行”。
- 期限：最长不超过 2 年；经原审批程序批准可延期 1 次、不超过 1 年，累计不得超过 3 年。
- 试行期内责任单位应跟踪实施情况，期满前修订并发布正式制度。

### 4.5 一致性

- 不同制度对同一事项的**定义、表述应保持一致**，不得相互冲突。
- 下位制度应依据上位制度制定；上位制度更新导致冲突的，须在集中清理周期内完成修订或废止。
- 制度名称原则上与上级单位同类制度保持一致。
- 涉及“抄送”“附件”“参考依据”等要素时，与《公文处理办法》口径对齐。

## 五、docx 生成参数速查（可直接落 XML）

```python
# 节属性
pgSz  = {'w': '11906', 'h': '16838'}                       # A4 纵向
pgMar = {'top': '2041', 'bottom': '2041', 'left': '1531',
         'right': '1531', 'header': '851', 'footer': '992', 'gutter': '0'}

# 段落（所有段落统一：段前段后 0 + 固定行距 30 磅）
spacing_generic = '<w:spacing w:before="0" w:after="0" w:line="600" w:lineRule="exact"/>'
# 有序号的段另加首行缩进 2 字符（三号）
ind_2chars      = '<w:ind w:firstLineChars="200" w:firstLine="640"/>'
# 章/节标题须显式清零缩进，否则继承样式缩进会走位
ind_zero        = '<w:ind w:leftChars="0" w:left="0" w:firstLineChars="0" w:firstLine="0"/>'

# run 字体（正文/条/款/项/目）
rFonts_body = '<w:rFonts w:ascii="Times New Roman" w:hAnsi="Times New Roman" w:eastAsia="仿宋_GB2312" w:cs="Times New Roman" w:hint="eastAsia"/>'
sz32        = '<w:sz w:val="32"/><w:szCs w:val="32"/>'     # 三号
# 章标题
rFonts_zhang = '<w:rFonts w:ascii="黑体" w:hAnsi="黑体" w:eastAsia="黑体" w:cs="黑体" w:hint="eastAsia"/>'
# 节标题（仿宋加粗）
rFonts_jie   = rFonts_body.replace('w:hint="eastAsia"', 'w:cs="仿宋_GB2312" w:hint="eastAsia"') + '<w:b/><w:bCs/>'
# 条号
rFonts_tiao  = rFonts_body + '<w:b/><w:bCs/>'                # 仿宋加粗（默认）
# rFonts_tiao = rFonts_zhang                                # 或改用黑体（备选口径）
# 文件标题
rFonts_title = '<w:rFonts w:ascii="方正小标宋简体" w:hAnsi="方正小标宋简体" w:eastAsia="方正小标宋简体" w:cs="方正小标宋简体" w:hint="eastAsia"/>'
sz44         = '<w:sz w:val="44"/><w:szCs w:val="44"/>'     # 二号
```

**段落 `<w:pPr>` 子元素顺序**（严格，顺序错 Word 静默忽略）：
`pStyle → keepNext → keepLines → pBdr → shd → spacing → ind → contextualSpacing → jc → outlineLvl → rPr`
